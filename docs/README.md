# CATMS Backend Documentation

This directory contains technical documentation for the CATMS Python FastAPI backend service.

## Documentation Structure

- `architecture.md`: Backend architecture, layers, and design decisions.
- `database.md`: Database connectivity, MySQL configuration, and migration guides.
- `api-reference.md`: Overview of endpoints, request/response models, and authentication.
- `setup.md`: Local environment setup, dependencies, and execution instructions.

Documentation will be expanded incrementally alongside backend development.
